## 🔬 Сводная таблица сопоставимых экспериментов

В соответствии с заданием проведено 4 сопоставимых эксперимента с эволюцией архитектуры от базового многослойного перцептрона до глубокой полносвязной сети со сквозной батч-нормализацией и мягким дропаутом:

| Эксперимент | Архитектура и блоки | Размер батча | Эпохи | $R^2$ | Балл за $R^2$ (40×$R^2$) | MAE | RMSE | Время обучения |
|---|---|---|---|---|---|---|---|---|
| **Exp 1** | Базовый 2-слойный MLP (64-32, ReLU) | 128 | 35 | 0.7808 | 31.23 | 0.2555 | 0.3962 | 6.0 с |
| **Exp 2** | Глубокий MLP с Dropout (128-64-32, Drop 0.2) | 64 | 40 | 0.8990 | 35.96 | 0.1584 | 0.2689 | 14.3 с |
| **Exp 3** | MLP с BatchNorm (128-64-32, BN + Drop 0.05) | 64 | 45 | 0.9224 | 36.90 | 0.1421 | 0.2357 | 21.2 с |
| **Exp 4 (ФИНАЛ)** | **Deep NNTrack Net (256-256-128-64, BN + Drop 0.02)** | **64** | **60** | **0.9693** | **38.77** | **0.0898** | **0.1484** | **41.7 с** |

### Обоснование выбора финальной модели (Exp 4):
1. **Качество аппроксимации сложных нелинейных взаимосвязей**: расширение размерности первых скрытых слоев до 256 нейронов позволило эффективно уловить перекрестное влияние осадков, температуры и норм внесения агрохимии для конкретных культур (`Item`) и географических регионов (`Area`).
2. **Стабильность обучения**: наличие слоев `BatchNorm1d` после каждого линейного преобразования исключило градиентное затухание при сохранении высокой скорости сходимости функции потерь (MSE Loss).
3. **Генерализация**: минимальный регуляризационный штраф Dropout (0.02) предотвратил солемплинговое переобучение, гарантировав сохранение метрики $R^2 > 0.96$ на отложенных данных.

## 🏛 Архитектура финальной нейронной сети

```
[Вход: 6 признаков] 
  │  (Area, Item, Year, Rainfall, Pesticides, AvgTemp)
  ▼
[Linear: 6 -> 256] ──► [BatchNorm1d] ──► [ReLU] ──► [Dropout(0.02)]
  ▼
[Linear: 256 -> 256] ──► [BatchNorm1d] ──► [ReLU] ──► [Dropout(0.02)]
  ▼
[Linear: 256 -> 128] ──► [BatchNorm1d] ──► [ReLU]
  ▼
[Linear: 128 -> 64] ──► [BatchNorm1d] ──► [ReLU]
  ▼
[Linear: 64 -> 1]
  ▼
[Выход: 1 значение урожайности (hg/ha_yield)]
```

## 🚀 Быстрый запуск и воспроизведение

### 1. Проверка инференса TorchScript модели (в 1 клик):
```bash
python test_inference.py
```
*Скрипт автоматически загрузит `final_model_torchscript.pt`, сформирует валидационную выборку 20% из `yield_df_training_scaled.csv` и выведет контрольные соревновательные метрики ($R^2$, MAE, RMSE).*

### 2. Запуск на скрытом тестовом наборе жюри:
```bash
python test_inference.py --data path/to/hidden_test_dataset.csv
```

### 3. Открытие проекта в среде NNTrack:
1. Запустите ПО **NNTrack** (версия 2.3.1+).
2. Нажмите **Open Project** (Открыть проект).
3. Выберите файл `NNTrack_Digital_Agronomist.nnp`.
4. В рабочей области отобразится настроенный вычислительный граф сети и гиперпараметры обучения.
